# Farm-s — চালাবন ফার্ম

গাজীপুর-অনুপ্রাণিত বাংলাদেশি খামার-জীবনের গেম (Android APK)।

- **খেলা:** `game/` — অফলাইন ওয়েব গেম (Canvas 2D), পরীক্ষা: `node game/tests/test.js`
- **Android:** `android/` — WebView-এ গেমটি চালায়। APK বানায় `.github/workflows/android-release.yml`।
- **রিলিজ ও APK ডাউনলোড:** GitHub Releases পেজ।
- **ডকুমেন্ট:** `docs/` (GDD, চরিত্র ডিজাইন, বন্ধুত্ব শিট, ইনস্টল গাইড)।
- **পুরোনো গবেষণা নথি:** রিপোর্টের বাকি `.md` ফাইলগুলো (ম্যাপ, ঋতু, উদ্ভিদ, ইঞ্জিন গবেষণা) অপরিবর্তিত রাখা হয়েছে।
