# চালাবন ফার্ম — গেম ডিজাইন ডকুমেন্ট (GDD)

**সংস্করণ:** ১.০ (প্রথম খেলার উপযোগী সংস্করণ)  
**তারিখ:** ১৩ অক্টোবর ২০২৬  
**প্ল্যাটফর্ম:** Android (APK, landscape, অফলাইন)  
**জেনার:** খামার + জীবন-সিমুলেশন (Stardew-ধাঁচের অনুভূতি, নিজস্ব বাংলাদেশি জগৎ)

## ১. এক বাক্যে
গাজীপুরের লালমাটির খামার, বাইদ, শালবন আর চালাবন গ্রামের ছয় মৌসুমে নিজের খামার গড়ো, মানুষের সাথে বন্ধুত্ব করো, আর দিনের শেষে সুখে ঘুমাও।

## ২. পিলার (সিদ্ধান্তের মাপকাঠি)
1. **দেশজ পরিবেশ:** টিনের চাল, লুঙ্গি-গামছা-টোকা, পুকুর-ঘাট, শালবন, ঋতু।
2. **শান্ত দৈনন্দিনতা:** চাষ, পানি, মাছ, বিক্রি, বন্ধুত্ব — নিজের গতিতে।
3. **ন্যায্য চাপ:** শক্তি (এনার্জি) ফুরালে ঘুমাতে হয়। রাত ২টায় জোরে ঘুম; টাকা বা সেভ হারায় না।
4. **মোবাইলে আরাম:** বড় বোতাম, বামে জয়স্টিক, অফলাইন, সেভ নিজে থেকে।

## ৩. প্রযুক্তি সিদ্ধান্ত (এবং কেন Unity নয়)
| বিষয় | সিদ্ধান্ত | কারণ |
|---|---|---|
| ইঞ্জিন | নিজস্ব ছোট JavaScript রানটাইম (Canvas 2D) | Unity-তে APK বানাতে ইউনিটি লাইসেন্স, ডেস্কটপ-এডিটর ও ক্লাউড বিল্ড লাগে; এই পরিবেশে তা সম্ভব নয়। ওয়েব প্রযুক্তি দিয়ে গেম বানিয়ে GitHub Actions-এ সরাসরি APK বানানো যায়। |
| APK-এর আবরণ | Android WebView-এ লোড হওয়া অফলাইন গেম | সাধারণ Android সেটআপ, কোনো বাইরের লাইব্রেরি নেই, তাই বিল্ড ভাঙার ঝুঁকি কম |
| গ্রাফিক্স | কোড দিয়ে আঁকা (প্রসিডিউরাল), কোনো বাইরের ছবি নেই | কপিরাইট ঝুঁকি নেই, ফাইল ছোট |
| ফন্ট | Hind Siliguri (SIL OFL লাইসেন্স) | বাংলা যুক্তাক্ষর ও কার-চিহ্ন ঠিকভাবে দেখায় |
| সেভ | ফোনের লোকাল স্টোরেজ (localStorage) | অ্যাপ আপডেটে থাকে |

> **সিদ্ধান্ত লগ:** ২০২৬-১০-১৩ — পূর্বের নথিতে Unity 6.3 LTS লক করা ছিল। এই সেশনে ডেস্কটপ-এডিটর বা Unity লাইসেন্স নেই এবং শুধু GitHub Actions-এ APK চাওয়া হয়েছে, তাই প্রথম খেলার উপযোগী সংস্করণ ওয়েব-ভিত্তিক বানানো হয়েছে। ভবিষ্যতে Unity-তে পোর্ট করা সম্ভব; গেমের নিয়ম `game/js/engine.js`-এ ডেটা-নির্ভর ও পরীক্ষিত, তাই সেটি সহজে স্থানান্তরযোগ্য।

## ৪. মানচিত্র (প্রথম সংস্করণে তিনটি)
| জায়গা | উদ্দেশ্য | বিশেষত্ব |
|---|---|---|
| **লালমাটি ফার্ম** | চাষ, বাড়ি, বিক্রয়-বাক্স | লাল মাটি, পুকুর ও পাড়, বাঁশঝাড়, স্কেয়ারক্রো |
| **চালাবন গ্রাম** | দোকান, গ্রামবাসী, বিদ্যালয় | মুদি দোকান, রিকশা স্ট্যান্ড, কুয়া, ছোট পুকুর |
| **আমাদের ঘর** | ঘুম, সেভ | বিছানা, কাঠের বাক্স, টেবিল |

পরের সংস্করণে (পরিকল্পনা): নদীঘাট, শালবন, বাইদের ধানক্ষেত (বর্ষায়)।

## ৫. গেমের লুপ
```text
সকাল ৬টা → চাষ/পানি/মাছ → চালাবনে যাও, বন্ধুর সাথে কথা, বীজ কেনা
→ ফসল তোলো → বিক্রয়-বাক্সে বিক্রি → বিকেল/সন্ধ্যা
→ বাড়ি গিয়ে বিছানায় ঘুম → নতুন দিন (ফসল বাড়ে, আবহাওয়া বদলায়)
```

## ৬. মৌসুম ও আবহাওয়া
- ছয় মৌসুম: **গ্রীষ্ম, বর্ষা, শরৎ, হেমন্ত, শীত, বসন্ত**। প্রতি মৌসুম ১২ দিন, বছর ৭২ দিন।
- খেলা শুরু শরৎ (দিন ১ = মৌসুমের ১ম দিন) — ডেটায় `START_SEASON` দিয়ে বদলানো যায়।
- আবহাওয়া: রোদ, মেঘলা, বৃষ্টি। বর্ষায় বৃষ্টির সম্ভাবনা সবচেয়ে বেশি। বৃষ্টির দিনে সব কোদাল-করা জমি নিজে থেকে ভিজে যায়।
- মৌসুম বদলালে যে ফসল সেই মৌসুমের নয় তা নষ্ট হয় (খেলার ন্যায্য চাপ)।

## ৮. নিয়ন্ত্রণ
- **মোবাইল:** বাম নিচে জয়স্টিক; ডান নিচে **A** (কাজ), হাতের জিনিস বদলানো, ঝোলা 🎒, ডায়েরি 📔, মেনু ☰।
- **কম্পিউটার (পরীক্ষার জন্য):** তীর/WASD, E বা Space = কাজ, Q/R = জিনিস বদল, I = ঝোলা, J = ডায়েরি, Esc = মেনু।

## ৯. এখনো যা নেই (পরিষ্কার স্বীকারোক্তি)
- সম্পূর্ণ গল্প ও শেষ (ending) নেই; খেলা ক্রমাগত চলে।
- নদীঘাট, শালবন, বাইদ মানচিত্র নেই।
- হাতে-আঁকা শিল্পকর্ম ও ফ্রেম-বাই-ফ্রেম অ্যানিমেশন নেই।
- ভয়েস বা সংগীত নেই; শুধু ছোট সাউন্ড-ইফেক্ট (কোদাল, পানি, মুদ্রা, মাছ ধরা)।
- স্মার্টফোনে বাস্তবে কতটা সুন্দর চলবে তা একটি বাস্তব ফোনে পরীক্ষা করে জানাতে হবে।

## ১০. পরীক্ষা
- `node game/tests/test.js` — মানচিত্র, ক্যালেন্ডার, চাষ, অর্থনীতি, বন্ধুত্ব, সেভ — ২১টি পরীক্ষা। প্রতিটি রিলিজের আগে GitHub Actions এগুলো চালায়।
